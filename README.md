# Git Repo Exchanges

> A script that moves GitHub repositories from one account to another.

![Python](https://img.shields.io/badge/Python-3.x-3776AB?logo=python&logoColor=white)
![License](https://img.shields.io/badge/License-MIT-green)


## What It Does

Lists the repositories of a source account and recreates or transfers them to a target account through the GitHub API.

## Quick Start

```bash
git clone https://github.com/dastonbek8747/git_repo_exchanges.git
cd git_repo_exchanges
pip install requests
python main.py
```

Set your GitHub token in the environment before running. Never commit a token.
